# Инструкция по использованию / Manual for use
🇷🇺 - 
  1.Очистка кеша - Функция которая удаленяет временные файлы, которые программы и система сохраняют, чтобы быстрее загружать данные при повторном обращении к ним.
  2.Поиск файлов - Функция которая помогает в быстром способе найти любой файл на вашем персональном компьютере (работает как Everything, но в 10 раз быстрее.)
  3.Восстановление - Восстановление нерабочих/плохо работающих/сломанных функций после повреждений.
  4.Антивирус - Управление Windows Defender, можно его просто выключить навсегда, и так-же обратно включить.
  5.Система - Информация о вашей системе (Работает плохо так как это Python btw).

🇺🇸 - 
1. Cache clearing — a function that deletes temporary files that programs and the system save to load data faster when accessed again.
2. File search — a function that helps you quickly find any file on your personal computer (works like Everything, but 10 times faster.)
3. Recovery — restoring non‑functioning/poorly functioning/broken functions after damage.
4. Antivirus — managing Windows Defender; you can simply turn it off permanently and then turn it back on.
5. System — Information about your system (works poorly because it’s Python, btw).
